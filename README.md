# Python Arithmetic Operators

## Explanation

This program demonstrates the basic arithmetic operators available in Python using two numbers.

## Problem Statement

Write a Python program to perform addition, subtraction, multiplication, division, modulus, exponentiation, and floor division on two numbers.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Modulus
* Exponentiation
* Floor division
* User input

## How It Works

The program accepts two numbers from the user and applies different arithmetic operators to them.

## Technologies Used

* Python 3

## Program Flow

1. Enter the first number.
2. Enter the second number.
3. Perform arithmetic operations.
4. Display the results.

## Sample Input

```text id="0u3jqe"
Enter first number: 10
Enter second number: 3
```

## Sample Output

```text id="j9bq2t"
Addition: 13
Subtraction: 7
Multiplication: 30
Division: 3.3333333333333335
Modulus: 1
Exponentiation: 1000
Floor Division: 3
```
